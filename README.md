# Buddy System

18+ body-doubling calls. List a task. The phone rings. You work. You hang up.

**This repo is the source.** GitHub Pages cannot run the live app (login codes, matching, and calls need a server). Use the shareable site from the Buddy System preview to actually call someone.

## What it does

- Email login with a 6-digit code
- Live feed of people who are open
- Book a window; it rings at that time
- Campus tab after a school `.edu` code
- Audio by default, camera optional
